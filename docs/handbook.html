Anno 1602 Extensions

Bigger worlds, stronger rivals, more life at sea and two campaigns with a story. Everything runs in memory, no game file is changed.

Setting sail

  1. Open “Anno 1602 – Extensions” on the desktop (on a German Windows: “Anno 1602 – Erweiterungen”).
  2. Choose the options or use a button: Everything big (maximum), For campaigns (campaigns as intended) or Reset to defaults.
  3. Play with extensions. In the game Single Player → New Game: the endless game at the top, the campaigns at the very bottom under Own Scenarios.
  4. Press F7 for up to 16× speed. After attack messages the game switches back by itself; then press F7 again.

Small and big maps

Every scenario has two versions. With Start original the classic map with 17 to 20 islands applies. With Play with extensions, map size 1000 × 700 or bigger and More islands the big version applies: up to 50 islands, more resources and natives. A tick above only stores in this browser which chapters you have completed.

The helmsman’s advice

Build a warehouse earlyWith strong pirates the game is over as soon as your only ship sinks and you have no settlement.
Gold options and campaignsYour starting gold and the rivals’ gold replace the scenario’s gold. The “For campaigns” button sets both to “As per difficulty”.
Saves from the big worldLoad them only with “Play with extensions” and the same map size. Leave the black window open until the game has ended.
To another PCUnzip the ZIP from GitHub (Code → Download ZIP), double-click install.cmd.
